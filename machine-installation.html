FEATURED COMPLETED PROJECT

Kitamura KNC-20F CNC Lathe Retrofit

FANUC control system → Syntec 22TA

Successfully commissioned for production

Project overview

Customized an existing Kitamura KNC-20F CNC turning lathe by converting its original FANUC control system to a Syntec 22TA controller. The work covered controller integration, servo configuration, spindle parameter tuning and electrical I/O integration.

Engineering scope

  • Controller conversion: Syntec 22TA integration with the existing machine system.
  • Servo configuration: Servo drive and motor interface setup.
  • Spindle control: Parameter setup and tuning to achieve the required operating performance.
  • Electrical integration: Wiring and machine I/O signal integration.

Project outcome

The converted machine completed functional checks and production trials and was returned to production use.
